# Changelog pattern reference

Use this reference only as a reminder to preserve the user's existing `CHANGELOG.md` style after first reading the real file in the workspace.

Observed example pattern from the current project:

- Title: `# Changelog`
- Intro paragraph explaining that notable changes are documented there.
- Semantic Versioning note.
- Horizontal separator: `---`
- Version heading pattern: `## [version] - YYYY-MM-DD`
- Category heading pattern with emoji: `### ♻️ Refactor`
- Bullet list with short, action-focused entries.

Behavior rules:

- The workspace `CHANGELOG.md` is the source of truth.
- Match its structure exactly.
- Only add or adjust the minimum required lines.
- Keep entries concise and parallel in style.
